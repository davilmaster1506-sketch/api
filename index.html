Address mapping

For an address a, the prototype selects:

row = floor(a / 4)
bank = (a mod 4) XOR (floor(a / 4) mod 4)

This mirrors the address mapping in PixelRAM v0.57.

Important

This is a browser-based software model. It does not connect to the Mali GPU, replace system RAM, modify Roblox, or increase actual FPS.
